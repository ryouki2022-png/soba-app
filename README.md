# 🍜 そば記録アプリ（プロトタイプ）

食べたそばを記録するためのモバイル対応 Web アプリです。

## できること

- **そばの記録** — 店名・メニュー・温かい/冷たい・こしの強さ・値段・総合評価・写真・メモ・日付を保存
- **Google マップ連携** — マップの共有リンクを貼ると、店名と位置情報を自動で読み取り（フルURL形式に対応）
- **一覧・検索・絞り込み** — 店名/メニュー/メモで検索、温かい・冷たいでフィルタ
- **統計表示** — 記録数・お店の数・平均評価をトップに表示
- **編集・削除** — 記録の修正や削除
- **データ保存** — ブラウザの localStorage に保存（サーバー不要。プロトタイプ用）

## 技術スタック

- Vite + React + TypeScript
- 状態管理・永続化は localStorage（バックエンドなし）
- スタイルは素の CSS（モバイルファースト）

## 開発

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（型チェック込み）
npm run preview  # ビルド結果をプレビュー
```

開発サーバー起動後、表示された URL（既定では http://localhost:5173 ）をスマホ・PC のブラウザで開いてください。


## Google マップ連携について

「リンクをコピー」などで得られる **フルURL** から店名・座標を抽出します。

```
https://www.google.com/maps/place/神田まつや/@35.69,139.76,17z/...
→ 店名「神田まつや」を自動入力
```

短縮URL（`maps.app.goo.gl` / `goo.gl/maps`）はリダイレクト先をブラウザから取得できない（CORS制約）ため、自動取得はできません。その場合は店名を手入力してください。
> 将来的に短縮URLにも対応する場合は、リダイレクトを解決する小さなサーバー側エンドポイントが必要になります。
