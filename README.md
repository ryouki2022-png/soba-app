# 📒 きろくノート（そば・生活）

「そば記録」と「生活記録（体重・食事・勉強）」をひとつにまとめた、モバイル対応の記録アプリです。最初の画面でどちらを使うか選びます。PWA対応で、ホーム画面に追加すると全画面のアプリとして起動します。

## できること

### 🍜 そば記録
- **記録** — 店名・複数メニュー・トッピング・温かい/冷たい・こしの強さ・値段・総合評価・写真・メモ・日付
- **場所の登録（3通り）**
  - 🔎 **店名で場所を検索** — 店名から候補を検索して位置を設定（OpenStreetMap Nominatim、APIキー不要）
  - 📍 **現在地を使う** — お店で記録するとき、その場の位置をワンタップで設定
  - **Google マップのリンク貼り付け** — フルURLなら店名・位置を自動取得（貼った瞬間に反映）。短縮URL（`maps.app.goo.gl`）は仕組み上読み取れないため、上の2つの方法へ誘導します
- **お店ごと管理** — 店単位で集計（訪問回数・平均評価・値段帯・温/冷）、その店の全記録を時系列表示
- **賢い入力** — 2回目以降は店名から過去訪問を表示し、前回のマップリンク・位置情報を自動補完
- **🗺️ マップ** — お店単位のピン表示＋**登録したお店の一覧**。一覧をタップすると地図がその店へ移動。位置情報のないお店も一覧に表示され、登録漏れに気づけます
- **📊 グラフ** — 評価の推移（折れ線）、月別の記録数（棒）
- **📋 データ** — 一覧（表）、JSON/CSV書き出し、JSONから復元
- **検索・絞り込み** — 店名/メニュー/トッピングで検索、温かい・冷たいでフィルタ。一覧は「食べた日」順
- **Google マップで開く** — URL未登録でも、登録した位置や店名検索で地図を開けます

### 📔 生活記録
- **体重** — 0.1kg単位のステッパー（±0.1 / ±0.5 / ±1.0）と数値入力、**前回比を色分け表示**
- **食事** — 朝・昼・夜・おやつごとにメモと「外食」フラグ。その日のそば記録も自動表示
- **勉強時間** — クイックボタン（+15分〜+1時間）と直接入力
- **グラフ** — 体重の変化・勉強時間を 1週間 / 1ヶ月 / 3ヶ月 / 全期間で表示
- **履歴** — 日別のバッジ表示、タップで編集、**CSV書き出し**

### 共通
- スマホの**「戻る」ボタン対応** — 詳細画面やサブアプリから前の画面へ戻れます（アプリが閉じません）
- **☁️ GitHub 自動同期** — 記録を自分のプライベートリポジトリへ自動保存。ブラウザ側のデータが消えても、次に開いたとき自動で復元。複数端末・Safari／ホーム画面アプリ間でもデータを共有できます（設定手順はアプリ内に表示）
- データは端末内でも **localStorage + IndexedDB の二重保存**（片方が消えても自動復旧）＋**日ごとの自動スナップショット**（操作ミスからの復元用）
- **🛟 データ救出** — 保存状態の診断、スナップショットからの復元、別ブラウザに残ったデータの回収手順を案内
- **バックアップ／復元** — ホーム画面から全データを1つのJSONで書き出し・読み込み
- **PWA** — ホーム画面に追加で全画面起動・オフライン対応

### データが消える問題について（重要）
localStorage / IndexedDB はどちらも**ブラウザ内**の保存領域なので、iOS（Safari）は
「7日間サイトを使わない」「ストレージ逼迫」「履歴の消去」などで**両方まとめて削除**することがあります。
また、Safari で開いた場合と「ホーム画面に追加」から開いた場合は**保存領域が別々**です。
根本対策として、アプリ内の「☁️ 同期」から GitHub 自動同期をオンにしてください。
以降はブラウザ側が消えても、起動時に GitHub から自動復元されます。

## 技術スタック

- Vite + React + TypeScript
- グラフは依存ライブラリなしの自作SVG（`src/charts/`）
- 地図は Leaflet + OpenStreetMap、場所検索は Nominatim（いずれもAPIキー不要）
- PWA は vite-plugin-pwa
- 永続化は localStorage + IndexedDB の二重化＋日次スナップショット（`src/lib/store.ts`）
- クラウド同期は GitHub Contents API（`src/lib/sync.ts`、ユーザー自身のプライベートリポジトリへ保存。専用サーバーなし）

## 開発

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（型チェック込み）
npm run preview  # ビルド結果をプレビュー
```

## 公開（GitHub Pages）

`main` 系の作業ブランチへ push すると、GitHub Actions（`.github/workflows/deploy.yml`）が
自動でビルドして GitHub Pages へデプロイします。公開URL: https://ryouki2022-png.github.io/soba-app/

## メモ
- Google マップの短縮URL（`maps.app.goo.gl`）はブラウザのCORS制約で情報を自動取得できません。アプリ内の「店名で場所を検索」「現在地を使う」で位置を登録できます。
- 地図のピンは位置情報のあるお店に表示されます。位置情報のないお店もマップ画面の一覧から確認できます。
